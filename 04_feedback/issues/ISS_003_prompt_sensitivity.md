## 내용
현재 실험은 단일 System Prompt (Zero-shot)만 사용하여 다음 문제가 발생한다:

1. **인과 관계 불명확**: Llama의 저조한 성능이 모델 자체 한계인지, 프롬프트 부적합인지 구분 불가
2. **실험 설계 게으름 인식**: 단 하나의 프롬프트로 모델 성능을 단정 짓는 것은 실험 설계의 엄밀성 부족
3. **Prompt Sensitivity**: Llama-3.1은 프롬프트에 민감할 수 있으며, Few-shot이나 CoT 적용 시 결과가 달라질 수 있음

## 조치 사항
- [ ] Few-shot 프롬프트 설계 (취약/안전 예시 1~2개 포함)
- [ ] Chain-of-Thought 프롬프트 설계 ("단계별로 분석하라" 지시)
- [ ] 3가지 프롬프트 전략(Zero-shot, Few-shot, CoT) × 2 모델 × 9 파일 = 54건 감사 실행
- [ ] 프롬프트 전략별 성능 비교 Table 추가
- [ ] 또는 Threats to Validity에서 single-prompt 실험의 한계를 명시하고 Future Work으로 제시
